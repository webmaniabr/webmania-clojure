# Exemplo de homologação

[examples/homologacao](.) contém um exemplo opcional que percorre leituras, o ciclo NF-e e o ciclo NFS-e em homologação (`ambiente` 2): emissão, consulta, arquivos, cancelamento e consulta final. Ele só envia requisições com `WEBMANIA_LIVE=1`; sem isso imprime `{"result":"blocked"}` e sai com 77. URLs base, credenciais e payloads vêm apenas de variáveis de ambiente (`WEBMANIA_API1_BASE_URL`, `WEBMANIA_FILES_BASE_URL`, `WEBMANIA_API2_BASE_URL`, `WEBMANIA_CONSUMER_KEY`, `WEBMANIA_CONSUMER_SECRET`, `WEBMANIA_ACCESS_TOKEN`, `WEBMANIA_ACCESS_TOKEN_SECRET`, `WEBMANIA_ISSUER_TOKEN`, `WEBMANIA_LIVE_SCOPE`, `WEBMANIA_LIVE_NFE_PAYLOAD`, `WEBMANIA_LIVE_NFSE_PAYLOAD`, `WEBMANIA_LIVE_LEDGER`, `WEBMANIA_LIVE_ALLOWED_HOSTS`). `WEBMANIA_LIVE_ALLOWED_HOSTS` é obrigatória: lista separada por vírgulas que precisa conter o host de cada URL base; ausente ou vazia, o exemplo imprime `{"result":"blocked"}` e sai com 77 antes de qualquer requisição. Os payloads precisam ter, no nível superior, `ambiente` igual ao número inteiro JSON `2`; outro valor, inclusive o texto `"2"`, também bloqueia com 77. A saída padrão tem uma linha JSON por passo, sem identificadores, valores do payload ou credenciais; uma mutação nunca é reenviada e um resultado desconhecido encerra com 1. Um documento que a emissão não devolve como `aprovado` (em processamento, em contingência ou reprovado) só é consultado: o exemplo não envia outra mutação para ele e termina com 1. O ledger em `WEBMANIA_LIVE_LEDGER` precisa ser gravável antes da primeira mutação e guarda os identificadores dos documentos para conciliação: mantenha-o privado. A compilação é offline: `WEBMANIA_MAVEN_REPO` (caminho absoluto) seleciona um repositório Maven local preparado, que precisa conter o JAR Java fixado, suas dependências e os plugins Maven da compilação; sem ela, o exemplo usa `~/.m2/repository`.

```sh
WEBMANIA_LIVE=1 WEBMANIA_LIVE_SCOPE=readonly WEBMANIA_LIVE_ALLOWED_HOSTS=webmania.com.br,nfe.webmania.com.br,api.webmania.com.br sh examples/homologacao/run.sh
```
